# 接口对接说明（给数据库管理老师）

> 用途：数据库里做了**新增**或**修改**后，调本工具的接口，把变化直接同步到简道云对应表单。
> 服务地址：`http://192.168.6.140:8088`（内网）。

---

## 一、接口

| 项 | 值 |
|---|---|
| 方法 / 路径 | `POST /api/sync/notify-batch` |
| 完整地址 | `http://192.168.6.140:8088/api/sync/notify-batch` |
| 鉴权 | 无 |

## 二、请求体

```json
{
  "table": "coaching_class",
  "database": "",
  "job": 1,
  "rows": [
    { "pk": "123", "class_number": "C001", "class_name": "二班", "class_ctime": "2026-09-11" }
  ]
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `table` | string | 是 | 源表名 |
| `job` | int | 是 | `1`=修改（只传改动字段即可），`2`=增加（传全部字段） |
| `rows` | array | 是 | 一行或多行数据（见下） |
| `database` | string | 否 | 数据库/schema 名；**仅 Oracle 必填**，MySQL 可省略 |

`rows` 里每一行是一个对象：

| 字段 | 说明 |
|---|---|
| `pk` | 该行主键值（固定用 `pk` 字段传，数字或字符串均可），**必填** |
| 其它字段 | 源表的**真实列名**和值（本工具按已配置的映射翻译成简道云字段） |

> **job=1 修改时**：只需传 `pk` + **改动的那几个字段**，没传的字段简道云里保持原值不变。
> **job=2 增加时**：需传 `pk` + 全部业务字段（新记录没有旧值可保留）。

## 三、各平台示例

| 平台 | 表 | 主键 | 需要传的源字段 |
|---|---|---|---|
| 大平台后台系统（班级） | `coaching_class` | id | `class_number` / `class_name` / `class_ctime` |
| 大平台后台系统（期次） | `groupbatch` | id | `classnumber` / `batchName` / `createDate` |
| 教务系统（Oracle） | `CLAZZ` | CLASS_ID | `CLASS_CODE` / `CLASS_NAME` / `BEGIN_YEAR` |
| 飞霞系统 | `db_plan_positon` | PlanPositonID | `ExamPlanName` / `ExamAreaName` / `ExamDate` |

> Oracle 的 `database` 取值为 `BFEC` / `SHFEC` / `GZFEC`（三个 schema 各对应一份）。

## 四、测试步骤

### 测「新增」（job=2）

```bash
curl -X POST http://192.168.6.140:8088/api/sync/notify-batch \
  -H "Content-Type: application/json" \
  -d '{
    "table": "coaching_class",
    "job": 2,
    "rows": [
      {"pk": "123", "class_number": "C001", "class_name": "二班", "class_ctime": "2026-09-11"}
    ]
  }'
```

返回 `{"ok":true,"success":1,"fail":0,...}` → 简道云里**新增了这条**。

### 测「修改」（job=1，只传改动字段）

只改了 `class_name`，就只传 `pk` + `class_name`：

```bash
curl -X POST http://192.168.6.140:8088/api/sync/notify-batch \
  -H "Content-Type: application/json" \
  -d '{
    "table": "coaching_class",
    "job": 1,
    "rows": [
      {"pk": "123", "class_name": "二班"}
    ]
  }'
```

返回 `{"ok":true,"success":1,...}` → 简道云里这条数据的 `class_name` 被更新，其它字段不变。

## 五、响应含义

| 返回 | 说明 |
|---|---|
| `{"ok":true,"success":N,"fail":0,"skipped":0}` | 成功 N 条 |
| `results[].reason = "not_found"` | job=1 但简道云里查不到这个 id（该先新增） |
| `results[].reason = "transform_skip"` | 被转换规则跳过（飞霞"在线考试/其他市名"） |
| `results[].reason = "missing_pk"` | 该行缺 `pk` 字段 |
| `results[].reason = "no_fields"` | job=1 但除了 `pk` 没传任何业务字段 |
| `{"detail":"表 xxx 未配置映射"}` | 表没在映射里，或 Oracle 忘了传 `database` |

## 六、在业务代码里对接（伪代码）

```python
import requests

def sync(table, rows, job, database=''):
    # 数据库 insert/update 提交成功后调用，失败重试 2~3 次
    requests.post('http://192.168.6.140:8088/api/sync/notify-batch',
                  json={'table': table, 'rows': rows, 'job': job, 'database': database},
                  timeout=5)

# 新增（job=2，传全部字段）
sync('coaching_class', [{'pk': 123, 'class_number': 'C001', 'class_name': '二班', 'class_ctime': '2026-09-11'}], 2)

# 修改（job=1，只传改动字段）
sync('coaching_class', [{'pk': 123, 'class_name': '二班'}], 1)
```

---

## 七、说明

- **对方直接传字段值**：调用方把这一行的源字段名和值一起传过来，本工具不再回查数据库，直接写简道云。
- **job 区分增改**：`job=2` 增加（直接新增，需全字段）；`job=1` 修改（本工具按「主键 + 数据类型」查到 data_id，**只更新对方传过来的字段**，其它字段不变）。
- **主键固定用 `pk` 字段传**，不用管源表主键列名叫什么。
- 简道云里的「数据类型」「平台」已按平台预先配置，无需老师关心。
