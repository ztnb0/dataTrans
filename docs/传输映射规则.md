## 四、转换规则详述

### 规则 1：批次号提取（batch_number）→ 项目编号

**来源**：`ExamPlanName`，样例：
- `2017年042批CFP投资规划`
- `2017年043批AFP金融理财基础（二）`
- `2017年051批EFP金融理财管理`

**规则**：用正则 `(\d+)批` 提取"批"前面的数字，作为项目编号。

| 样例 | 提取结果 |
|---|---|
| `2017年042批CFP投资规划` | `042` |
| `2017年043批AFP金融理财基础（二）` | `043` |
| `2017年051批EFP金融理财管理` | `051` |

- 实测批次号均为 **3 位补零**（042~057 等），正则 `(\d+)批` 直接取原数字串（保留前导零，如 `042`）。
- **无匹配兜底**（无"批"字样）：返回原字符串并告警（避免静默丢数据），预览中标红提示。

### 规则 2：市名提取 + "考场"（city_name）→ 项目名称

**来源**：`ExamAreaName`，格式为「省级简称 + 市名」，样例：
- `福建福州` → `福州考场`
- `广东广州` → `广州考场`
- `内蒙古呼和浩特` → `呼和浩特考场`

**算法**：
1. 去掉开头省级前缀（按省份表，长名优先匹配）；
2. 若去掉后为空（直辖市），市名 = 省名本身；
3. 去掉尾部 `市` 字；
4. 拼后缀 `考场`。

```python
PROVINCES = [
    '内蒙古', '黑龙江',            # 3 字自治区/省，优先
    '北京', '天津', '上海', '重庆', '香港', '澳门',
    '河北', '山西', '辽宁', '吉林', '江苏', '浙江', '安徽', '福建',
    '江西', '山东', '河南', '湖北', '湖南', '广东', '海南', '四川',
    '贵州', '云南', '陕西', '甘肃', '青海', '台湾',
    '广西', '宁夏', '新疆', '西藏',
]

def extract_city(area):
    a = area.strip()
    city = a
    for p in PROVINCES:
        if a.startswith(p):
            city = a[len(p):] or p   # 直辖市：北京北京 -> 北京
            break
    return city.rstrip('市')          # 江西南昌市 -> 南昌

project_name = extract_city(area) + '考场'
```

**样例核对**：
| 源值 | 市名 | 结果 |
|---|---|---|
| `福建福州` | 福州 | `福州考场` |
| `北京北京` | 北京 | `北京考场` |
| `内蒙古呼和浩特` | 呼和浩特 | `呼和浩特考场` |
| `江西南昌市` | 南昌 | `南昌考场` |

### 规则 3：ExamDate → 平台数据创建时间

- `ExamDate` 为 `date` 类型，直接作为**时间字段**映射（复用现有 `time_field` 机制）：
  - 作为「平台数据创建时间」写入（`normalize_value` 对 date 输出 `YYYY-MM-DD`）。
  - 同时可作为起始时间筛选条件（如需）。
- 无需新增转换逻辑。

## 五、边界情况与处理建议

### 5.1 `ExamAreaName` 特殊值
| 源值 | 现状算法结果 | 处理办法 |
|---|---|---|
| `广东其他` | `其他考场` | 无明确市名，排除不传（见「七、问题二」） |
| `陕西其他` / `浙江其他` 等 | `其他考场` | 同上 |
| `AFP在线考试AFP在线考试` | `AFP在线考试AFP在线考试考场`（乱） | 忽略跳过，不做映射传输（见「七、问题三」） |
| `EFP在线考试EFP在线考试` / `CFP在线考试CFP在线考试` | 同上 | 同上 |

### 5.2 项目编号不唯一（重要提醒）
- `项目编号 = 批次号`，但**批次号在多行间大量重复**：
  - 同一批次（如 `042`）覆盖多门课程（投资规划、员工福利、税务筹划、风险管理、案例分析）+ 多个考场。
  - 因此简道云中 `项目编号` 会大量重复，**不能当作唯一键**。
- 影响：若后续接入 `sync-feature-plan.md` 的"对账唯一键 = 项目编号"，此表会冲突，需另选唯一键或组合键（如 批次+市名+日期）。
- **已明确处理办法**：按「批次号 + 市名」去重，见「七、问题一」。

### 5.3 兜底策略
| 情况 | 处理办法 |
|---|---|
| `ExamPlanName` 无"批" | 返回原字符串 + 告警标记 |
| `ExamAreaName` 无明确市名（如"省+其他"） | 排除不传（见「七、问题二」） |
| `ExamAreaName` 为在线考试 | 忽略跳过（见「七、问题三」） |

## 七、待解决问题与当前解决办法

### 问题一：批次号重复（项目编号重复）
- **现象**：多条数据提取出的批次号（项目编号）相同。
- **解决办法（去重判断）**：当多条数据的批次号相同时，比较它们 `ExamAreaName` 提取出的**市名**是否不同：
  - **市名不同** → 全部传输；
  - **市名相同** → 只传输一条。
- **示例**：
  - 情况一：
    - 数据 1：批次号 `001`，`ExamAreaName` = `广东广州`
    - 数据 2：批次号 `001`，`ExamAreaName` = `广东深圳`
    - 市名不同（广州 ≠ 深圳）→ 两条都按映射传输到简道云。
  - 情况二：
    - 数据 1：批次号 `001`，`ExamAreaName` = `广东广州`
    - 数据 2：批次号 `001`，`ExamAreaName` = `广东广州`
    - 市名相同 → 只传输一条。

### 问题二：`ExamAreaName` 没有明确市名（如 "广东其他" 等）
- **解决办法**：遇到这类没有明确市名的值，先**排除不传**（跳过，不写入简道云）。

### 问题三：`ExamAreaName` = "AFP在线考试AFP在线考试" 等
- **解决办法**：这类值不做映射关系传输，直接忽略（跳过）。
